VERDICT-ARC design v1 review (2026-07-22, ex-ko lens): verdict REVISE. Direction (decide-by-default + temporal awareness) is KO-sound; four holes named.

**Why:** (1) Open/closed is a LIVE-SAM fact — extensions ride on amendments, the doc most likely missing from a snapshot; doc-prose "deadline past" alone = false-closed class (AUTO-F in my rubric). Deadline is datetime+tz, not a date. (2) Precedence "CLOSED wins regardless of read-completeness" inverts when the unread content is an AMENDMENT — amendments can extend deadlines AND remove bars (set-aside changes). Rule: unread amendment ⇒ cap everything to INCOMPLETE; unread non-amendment attachments follow stated precedence. Extends [[root2-completeness-gate-ruling]]. (3) Site-visit-past ≠ NO_BID: attendance is a bidder attribute (#575 profile class); "non-responsive" is sealed-bid vocabulary; route to hard caution/profile/escalation. Question-cutoff past never drives NO_BID. (4) Zero-false-BID stops being "by construction" once the verbatim veto becomes a semantic classifier (#557 shape-indiscriminable class) — it becomes a MEASURED gate: expanded adversarial gold-set, shape-allowlist doctrine, no vocab blocklists.

**How to apply:** If any temporal/CLOSED verdict arc resurfaces, check: live SAM re-fetch at verdict time; datetime+tz comparison with same-day=OPEN; amendment-supremacy in the precedence table; NO_BID(CLOSED) carries notice id + current SAM response date as the named gate; escalation calibrated on error rates, not a 15-25% quota.
