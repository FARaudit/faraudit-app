# HARD-BAR PIVOT V3 design review (2026-07-22) — grade D, REJECT as specified

Probe `scripts/audit-ai/_panel-pivot-probe.ts` (10 probes × 3 bindings, 17 BREAK / 13 OK, deterministic).
Ledger `ceo/PANEL-PIVOT-REDTEAM.md`. Verdict: treadmill re-coated — direction flip is genuine doctrine, but the
proof predicate is the same regex-window machinery with the list moved to the inclusion side.

Reusable structural findings (probe these on ANY future temporal-anchor or frame design):
- **Anchor-is-not-scarce**: offer-time deadline phrases ("prior to the quote due date") appear in benign admin
  clauses everywhere; an anchor REQUIREMENT without grammatical binding re-arms the comma-smuggle families
  (B1-1/B2-1 both re-fired under clause-level AND span-level binding — the 180-char window is the real defect,
  and no anchor logic fixes it). Always ask a design spec WHERE a required token must BIND.
- **Inverted selector**: real restriction-frame bars are drafted anchor-free ("Award is limited to holders of X");
  requiring an anchor on them selects AGAINST true bars and FOR glued admin sentences. Executed: 2/3 banked
  flagship true-fires die (SeaPort test:50/188, GSA-holder test:192) while both flagship over-fires return.
- **Anchor allowlist misses the FAR-canonical register** (live-verified 52.215-1): "exact time specified for
  receipt of offers" / "solicitation closing date and time" / "as of the date set for receipt of proposals" all
  outside (at|by|prior to|before)+(offer|proposal|...). Lists calibrate to informal phrasing; smuggles use it too.
- **H1 (allowlist-failure-direction-is-safe) dies at GOVERNANCE level even when the regex letter holds**: missing
  members starve branch A while the anchor-free set-aside branch keeps unit fire-count >0 → §5's "≈0 fires"
  retirement/arm metric mismeasures both ways. Inertness metrics must be per-CLASS recall vs hand labels, never
  unit fire-count. Also "safe while the veto stands" is vacuous when the arm is bundled WITH veto retirement.
- **H2 (present-tense possession is structurally offer-time) dies both axes**: (a) it's an open-class participle
  list (holding/possessing/certificated/QPL-listed/...); (b) executed false-NHR on #572 maintain-for-duration
  ("holding a SECRET FCL for the life of the contract ... eligible") and on eligible-to-PERFORM vs
  eligible-for-AWARD ("Only firms possessing a TS FCL are eligible to perform" — NISPOM invite-the-uncleared).
  Present tense = current-at-READING-time; temporal referent lives in the eventuality, unreadable by span regex.
- **Gate-set coherence check on any pivot spec**: V3's §6 required the 43-bank green, but the bank pins true-fires
  V3 deletes by design → unachievable gate → silent re-baseline risk. Diff the banked assertions against the
  design's intended behavior changes BEFORE ratifying a gate set.
- Probe-validity recurrence: my first H2 probes nulled on frame-3's {0,80} capture window, not the H2 logic —
  the confirm-which-predicate-killed-it rule (ULTRA-B1 lesson) caught it again; the {0,80} cap is itself a P2 under.
